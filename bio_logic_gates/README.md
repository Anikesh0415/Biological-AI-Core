# Noise-Tolerant Biological Boolean Logic Gates Simulation

## Overview
This repository contains a pure Python 3D simulation of a Leaky Integrate-and-Fire (LIF) wetware substrate tuned to a thermodynamic state of Self-Organized Criticality. By leveraging homeostatic synaptic scaling, the simulated neural tissue maintains an avalanche size distribution invariant of $\tau \approx 1.67$. This framework shifts the biocomputing paradigm away from brute-force electrical stimulation, utilizing natural thermodynamic wave propagation and constructive interference to execute complex logic natively.

## Features
*   **Scale-Free Criticality:** Accurate reproduction of directed percolation and critical neuronal avalanches ($\tau \approx 1.67$).
*   **Combinational Logic (AND/OR):** Noise-tolerant signal routing utilizing spatial clustering and constructive wave interference.
*   **Hebbian Learning (STDP):** Organic structural wiring and pathway potentiation via Spike-Timing-Dependent Plasticity.
*   **XOR Half-Adder:** Non-linear routing achieved via highly specific clusters of GABAergic inhibitory interneurons.
*   **SR Latch (Sequential Memory):** A 1-bit memory flip-flop sustained indefinitely by super-critical localized recurrent topologies.

## Installation & Execution

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/bio_logic_gates.git
   cd bio_logic_gates
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the primary STDP evaluation pipeline:
   ```bash
   python main.py
   ```

4. Explore advanced circuit logic (XOR and Memory):
   ```bash
   python half_adder.py
   python memory.py
   ```
