# Detection-Limit-in-OI

This repository contains the supplementary materials and analytical pipeline for the independent research paper: **"Detection Limits and Sub-Millisecond Network Dynamics in Macro-Scale Organoid Intelligence Arrays."**

## Overview
This study characterizes the high-frequency temporal signaling boundaries of neural organoids using the FinalSpark neuroplatform. By analyzing electrophysiological data, this project characterizes high-frequency sub-millisecond network bursts and defines the physical detection floor of standard 30 kHz Multi-Electrode Array (MEA) hardware[cite: 13].

## Repository Contents
*   **`organoid_intelligence_final_submission.pdf`**: The finalized manuscript detailing the methodology, results, and discussion of hardware detection limits[cite: 13].
*   **`sub_ms_burst_distribution.png`**: The primary visualization showing the distribution of sub-millisecond firing events and the hardware-imposed Nyquist-limit floor[cite: 13].
*   **`analysis_scripts/`**: Python scripts used to process raw data and compute Inter-Spike Intervals (ISIs).
*   **`data_summary/`**: Lightweight CSV files containing the summary statistics for the fs369 and fs437 organoid lifecycles.
